# MD Feature Extraction Data

This directory contains data used by the mean-difference feature extraction
pipeline.

- `inputs/addressivity_500_seed42/`: four input sets with 500 examples each.
- `inputs/experiment_datasets_extra_nonoverlap_from_4_13/`: additional
  non-overlap experiment input sets.
- `inputs/level1/` and `inputs/level2/`: level-specific input sets.
- `principal_variants/`: level3 principal-variant transformation data.
- `llama31_base/` and `llama31_it/`: extracted feature artifacts for Llama 3.1
  base and instruct runs.
- `selected_level3_llama_it.tar.gz`: archived selected level3 instruct
  artifacts.
